מסמך זה משרת את שלב 2 (בסיס למסמך `04-knowledge/cro.md`) ואת שלב 5 (סריקה עמוד-עמוד). לכל פריט: מה לבדוק, למה זה חשוב, ומה נחשב טוב. המספרים מבוססים על מחקרי Baymard ו-Nielsen Norman Group משנים שונות; בשלב 1 יש לאמת אותם.

## 1. עקרונות רוחביים (בכל עמוד)

- **בהירות לפני חוכמה.** בכל עמוד המבקר צריך לענות תוך שניות: איפה אני, מה יש כאן, מה הצעד הבא. סיסמאות חכמות שלא אומרות מה מוכרים מפסידות לכותרת פשוטה.
- **פעולה ראשית אחת.** לכל עמוד יש CTA ראשי אחד (בעמוד מוצר: הוספה לעגלה; בעגלה: המשך לתשלום). כל כפתור נוסף באותה בולטות מוריד את שיעור הלחיצה על הראשי.
- **שקיפות עלויות בכל שלב.** מחיר, משלוח, מסים, זמן אספקה: ככל שמוקדם יותר, כך פחות נטישה בצ'קאאוט. הפתעות בעלות הן הסיבה הראשונה לנטישה.
- **אמון ליד ההיסוס.** מדיניות החזרות ליד הכפתור, אבטחה ליד הכרטיס, ביקורות ליד המחיר. אותות אמון בפוטר עוזרים פחות, כי המבקר לא מגיע לשם ברגע הספק.
- **עקביות במסר.** מה שהובטח במודעה או בדף הבית (מבצע, משלוח חינם) מופיע גם בעמוד המוצר ובעגלה, אחרת המבקר חושד.

## 2. דף הבית

| בדיקה | מה נחשב טוב |
|---|---|
| הצעת ערך מעל הקיפול | כותרת שאומרת מה מוכרים ולמי, בידול אחד ברור (מחיר, איכות, משלוח, ייחודיות), ו-CTA אחד. בלי גלילה, בשני המכשירים. |
| נתיבים ראשיים | הקטגוריות המרכזיות נגישות מדף הבית תוך לחיצה אחת, בטקסט ולא רק בתמונות. |
| מבצעים ומסרים | מבצע אחד בולט עדיף על חמישה. הבטחות (משלוח חינם, החזרה חינם) בשורת הודעה קבועה. |
| הוכחה חברתית | דירוג כללי, מספר לקוחות, לוגואים או ציטוטים. מופיעים לפני שמבקשים מהמבקר משהו. |
| קרוסלות | קרוסלה שמתחלפת אוטומטית זוכה בדרך כלל ללחיצות בעיקר על השקופית הראשונה. אם יש, לוודא שהראשונה היא החשובה ביותר. |
| פופאפ כניסה | פופאפ שמופיע לפני שהמבקר ראה תוכן פוגע בהמרה אצל רוב האתרים. אם יש, לדחות אותו (זמן או גלילה) ולוודא סגירה קלה. |
| חיפוש | נגיש ובולט, במיוחד לחנויות עם קטלוג גדול. |

## 3. עמוד קטגוריה ורשימת מוצרים

| בדיקה | מה נחשב טוב |
|---|---|
| כרטיס מוצר | תמונה ברורה, שם, מחיר (כולל מחיר לפני הנחה אם יש), וריאציות (צבעים), דירוג, זמינות. מספיק מידע כדי להשוות בלי להיכנס לכל מוצר. |
| תמונה משנית במעבר עכבר / החלקה | מראה את המוצר מזווית שנייה או בשימוש. משפר כניסות למוצרים הרלוונטיים. |
| פילטרים | מותאמים לקטגוריה (מידה באופנה, נפח בקוסמטיקה), מציגים כמות תוצאות, קלים להסרה. פילטר מחיר עם טווח. |
| מיון | כולל "פופולריות", "מחיר", "חדש". ברירת המחדל הגיונית (לא לפי אלף-בית). |
| כמות ועימוד | 20 עד 60 מוצרים בעמוד עם "טען עוד" או עימוד. גלילה אינסופית מקשה לחזור למקום ולהגיע לפוטר. |
| מצב ריק | קטגוריה בלי מוצרים או פילטר בלי תוצאות מציעים מה לעשות. |
| הוספה מהירה לעגלה | עוזרת למוצרים פשוטים (בלי וריאציות); מבלבלת למוצרים עם מידות. |
| פירורי לחם | מראים איפה אני ומאפשרים לעלות רמה. |

## 4. חיפוש

| בדיקה | מה נחשב טוב |
|---|---|
| נראות | תיבת חיפוש גלויה (לא רק אייקון) בדסקטופ, אייקון ברור במובייל. |
| הצעות אוטומטיות | מוצרים, קטגוריות והשלמות תוך כדי הקלדה. |
| סובלנות | שגיאות כתיב, יחיד ורבים, עברית ואנגלית, מילים נרדפות, מק"ט. |
| תוצאות | רלוונטיות לפני הכל; אפשרות מיון ופילטר כמו בקטגוריה. |
| "אין תוצאות" | לא מבוי סתום: הצעות, קטגוריות, מוצרים פופולריים, יצירת קשר. |
| שאילתות מסוג "שאלה" | "מה מתאים ל..." לא מחזיר כלום. אם החנות מוכרת מוצרים שדורשים ייעוץ, כדאי עמוד מדריך. |

## 5. עמוד מוצר

זה העמוד הכי חשוב בחנות. הקונה מחליט כאן.

| בדיקה | מה נחשב טוב |
|---|---|
| תמונות | 5 עד 8 תמונות: המוצר לבד, בשימוש, פרטים, קנה מידה. זום אמיתי. וידאו קצר למוצרים שדורשים הדגמה. |
| שם וכותרת | שם ברור עם המאפיין המבדל. H1 אחד. |
| מחיר | בולט, ליד הכפתור, עם מחיר קודם אם יש הנחה, עם תשלומים אם רלוונטי, כולל מע"מ. |
| וריאציות | בורר ברור, וריאציה שאזלה מסומנת ולא נעלמת, תמונה מתחלפת לפי הבחירה. |
| כפתור הוספה לעגלה | בולט, בצבע ייחודי, בקיפול הראשון, טקסט ברור. במובייל: נשאר נגיש אחרי גלילה. |
| משלוח והחזרות ליד הכפתור | עלות, סף למשלוח חינם, זמן אספקה, מדיניות החזרה במשפט אחד. לא רק בעמוד מדיניות. |
| זמינות | "במלאי" או "יישלח תוך X ימים". מלאי נמוך רק אם אמיתי. |
| תיאור | עונה על שאלות הקונה (למי, למה, מה כלול, מידות, חומרים, תחזוקה), תועלות לפני מפרט, סרוק בקלות (כותרות, רשימות). |
| ביקורות | דירוג מעל הקיפול, ביקורות מלאות למטה, עם תאריכים, אפשרות סינון, ותשובות של החנות. אפס ביקורות גרוע מדירוג 4.2. |
| שאלות נפוצות | למוצר, לא לחנות. מפחיתות פניות לשירות ומגדילות ביטחון. |
| מוצרים משלימים | מתחת למידע הראשי, לא בין המחיר לכפתור. |
| טבלת מידות | לאופנה ונעליים: חובה, נגישה בלחיצה אחת ליד בורר המידה. |
| אותות אמון | אבטחה, אחריות, שירות. משפט אחד ליד הכפתור, פירוט למטה. |
| מחיר ליחידה | למוצרי צריכה: מחיר ל-100 גרם או ליחידה מאפשר השוואה. |

## 6. עגלה

| בדיקה | מה נחשב טוב |
|---|---|
| אישור הוספה | אחרי הוספה: מגירה או הודעה ברורה עם שני כפתורים: המשך קנייה, לתשלום. |
| תוכן העגלה | תמונה, שם, וריאציה, מחיר, כמות עם + ו-, הסרה בלחיצה אחת, שמירה לאחר כך. |
| סיכום | סה"כ מוצרים, משלוח (או הערכה), מסים, סה"כ לתשלום. בלי הפתעות בצ'קאאוט. |
| סף למשלוח חינם | "הוסיפו עוד 40 ₪ למשלוח חינם" עם פס התקדמות. מגדיל סל ממוצע. |
| כפתור לתשלום | בולט, מעל ומתחת לרשימה בעגלות ארוכות, טקסט "המשך לתשלום". |
| קופון | קיים אבל לא צועק. שדה קופון בולט שולח קונים לחפש קודים בגוגל, וחלקם לא חוזרים. |
| תשלום מהיר | Apple Pay, Google Pay, PayPal, Bit כבר כאן. |
| אמון | אבטחה, החזרות, יצירת קשר במשפט אחד. |
| עגלה נטושה | שמירת העגלה בין ביקורים, ואם יש מייל, תזכורת. |

## 7. צ'קאאוט

| בדיקה | מה נחשב טוב |
|---|---|
| רכישה כאורח | אפשרית ובולטת. חובת הרשמה היא סיבת נטישה מובילה. הצעת חשבון אחרי הרכישה, לא לפניה. |
| מספר שדות | כמה שפחות. Baymard: הצ'קאאוט הממוצע מכיל 11 עד 12 שדות, ורוב האתרים יכולים לרדת ל-7 עד 8. שדות מיותרים נפוצים: שם חברה, כתובת שנייה, אישור אימייל, כותרת. |
| כתובת חיוב | ברירת מחדל: זהה לכתובת משלוח. |
| מד התקדמות | מראה כמה שלבים יש ואיפה אני. |
| סיכום הזמנה | נראה בכל שלב (במובייל: מתקפל אבל נגיש). |
| אמצעי תשלום | לוגואים מוכרים, אפשרויות מקומיות (בישראל: תשלומים, Bit), ארנקים דיגיטליים. |
| שדה כרטיס | מזהה את סוג הכרטיס אוטומטית, מעצב מספרים, שדה תוקף בפורמט ברור. |
| שגיאות | ליד השדה, בזמן אמת אחרי יציאה מהשדה, בשפה אנושית ("מספר הטלפון צריך 10 ספרות" ולא "קלט לא תקין"). |
| מילוי אוטומטי | `autocomplete` נכון בכל השדות, במיוחד במובייל. |
| הסחות דעת | תפריט מלא, באנרים, קישורים החוצה: להסיר. להשאיר לוגו, אמון, ויצירת קשר. |
| אפשרויות משלוח | ברורות, עם מחיר וזמן, ברירת מחדל סבירה. |
| אבטחה | סמל מנעול, טקסט "תשלום מאובטח", לוגו של חברת הסליקה. |
| הרשמה לדיוור | לא מסומנת מראש (חוק הספאם בישראל, ואמון). |
| כפתור סופי | "לתשלום 249 ₪" עדיף על "שלח". |
| עמוד שגיאה | אם התשלום נכשל: מה קרה ומה לעשות, בלי לאבד את הפרטים שהוזנו. |

## 8. עמוד תודה

| בדיקה | מה נחשב טוב |
|---|---|
| אישור | מספר הזמנה, מה נקנה, לאן, מתי יגיע, איך עוקבים. |
| הצעד הבא | יצירת חשבון בלחיצה אחת (הפרטים כבר יש), הרשמה, שיתוף, המלצה. |
| שירות | איך יוצרים קשר אם יש בעיה. |

## 9. חשבון, מדיניות ותוכן

| בדיקה | מה נחשב טוב |
|---|---|
| התחברות | אפשרות בלי סיסמה (קוד לטלפון או למייל), התחברות חברתית, שחזור סיסמה פשוט. |
| מדיניות משלוחים | עמוד אחד: אזורים, מחירים, זמנים, מה קורה בחגים. קישור ממנו לעמוד המוצר ולעגלה. |
| מדיניות החזרות | כמה ימים, מי משלם על ההחזרה, איך עושים את זה, מתי מקבלים כסף. בהתאם לחוק. |
| אודות | אנשים אמיתיים, סיפור, כתובת פיזית. מגביר אמון במיוחד לחנויות לא מוכרות. |
| יצירת קשר | טלפון, וואטסאפ, מייל, שעות פעילות. טופס בלבד מרתיע. |
| תקנון | קיים, נגיש, ובעברית. |
| שאלות נפוצות | מאורגנות לפי נושא, ניתנות לחיפוש. |
