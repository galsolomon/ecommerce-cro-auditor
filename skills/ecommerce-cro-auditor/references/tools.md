## 1. הכלים של הסקיל עצמו

| סקריפט | קלט | פלט | דרישות |
|---|---|---|---|
| `init_audit.py` | כתובת, שם | תיקיית ביקורת ותדריך | Python 3.8+ |
| `crawl_site.py` | כתובת | `pages.json`, `summary.md`, צילומי מסך | Python 3.8+, Playwright לצילומים (`--no-browser` בלעדיו) |
| `merge_findings.py` | קובצי סוכנים | ממצאים מאוחדים, סתירות, סטטיסטיקה | Python 3.8+ |
| `build_report.py` | ממצאים מאוחדים | שלד דוח וכרטיסי A/B | Python 3.8+ |

התקנת Playwright: `pip install playwright` ואז `playwright install chromium`. בסביבות שבהן Chromium מותקן במקום אחר: `--executable-path`.

## 2. אנליטיקס ומשפך

| כלי | מה נותן | הערה |
|---|---|---|
| **Google Analytics 4** | משפך רכישה (צפייה במוצר, הוספה לעגלה, תחילת צ'קאאוט, רכישה), לפי מכשיר, מקור, עמוד נחיתה | חינם. דורש אירועי איקומרס מוגדרים; ברוב הפלטפורמות זה מובנה. הדוח החשוב ביותר לביקורת. |
| **Shopify Analytics** | שיעור המרה, סל ממוצע, נטישה, מקורות | מובנה. דוח "התנהגות קונים" (Online store conversion) מספיק לרוב הביקורות. |
| **WooCommerce Analytics** | הזמנות, מוצרים, קופונים | מובנה, פחות משפך. |
| Google Search Console | שאילתות, עמודים, ביצועים בחיפוש | חינם. עוזר להבין מה מחפשים ומה מביא תנועה. |

**מה לבקש מהמשתמש** (אם יש): שיעור המרה כללי ולפי מכשיר; שיעור נטישת עגלה וצ'קאאוט; שיעור הוספה לעגלה מעמוד מוצר; עשרת העמודים הנכנסים; שיעור יציאה בעמודי מוצר וקטגוריה. שלושים הימים האחרונים ואותה תקופה שנה קודם.

## 4. ניסויים A/B

| כלי | הערה |
|---|---|
| **Shopify**: אפליקציות ניסויים (Intelligems, Shoplift, ABConvert ואחרות) | Shopify Plus מאפשר יותר, במיוחד בצ'קאאוט. |
| **GrowthBook** | קוד פתוח, חינם לניהול עצמי. |
| **VWO, Optimizely, Convert, AB Tasty** | כלים מסחריים מלאים. |
| **PostHog** | ניסויים + אנליטיקס + הקלטות, קוד פתוח. |
| Google Optimize | נסגר ב-2023. אם מישהו מזכיר, להפנות לחלופה. |

**מתי ניסוי בכלל אפשרי**: כלל אצבע לניסוי על שיעור המרה: כמה מאות המרות לכל גרסה לאורך הניסוי, לפחות שבועיים (מחזור שבועי מלא, פעמיים), ולא בזמן מבצע גדול. חנות עם 50 הזמנות בחודש לא יכולה לגלות שיפור של 10% בניסוי; אצלה ההמלצה היא "יישום עם מדידה לפני ואחרי" ולא A/B. חישוב: מחשבון גודל מדגם (Evan Miller) עם שיעור ההמרה הנוכחי ואפקט מינימלי לגילוי (MDE) של 10% עד 20% יחסי.

**מה כרטיס ניסוי טוב מכיל** (ראה `assets/ab-test-card-template.md`): השערה במשפט אחד, מדד ראשי, מדד שמירה (שלא יורד: סל ממוצע, החזרות, פניות לשירות), גרסאות, גודל מדגם ומשך משוער, קריטריון הצלחה מראש.

## 6. כלים לפי פלטפורמה

| פלטפורמה | מה אפשר לשנות בלי מפתח | מה דורש מפתח או תוכנית גבוהה |
|---|---|---|
| **Shopify** | טקסטים, סקשנים בתבנית, אפליקציות (ביקורות, פופאפים, סף משלוח חינם), אמצעי תשלום, הגדרות צ'קאאוט בסיסיות | שינויי Liquid בתבנית; צ'קאאוט מותאם (Plus בלבד, דרך Checkout Extensibility) |
| **WooCommerce** | הגדרות, תוספים לכמעט הכל | תבנית, PHP, ביצועים (תלוי באחסון) |
| **Wix** | עורך ויזואלי, אפליקציות | מוגבל; קוד דרך Velo |
| **Magento / Adobe Commerce** | הגדרות אדמין | כמעט הכל דורש מפתח |
| **פלטפורמות ישראליות** (Konimbo, Quik ואחרות) | הגדרות ותבניות של הפלטפורמה | לבדוק מול הפלטפורמה מה ניתן |
| **אתר מותאם אישית** | תלוי | הכל דורש מפתח, אבל הכל אפשרי |

זה משפיע על ציון המאמץ: אותו שינוי הוא מאמץ 1 ב-Shopify עם אפליקציה ומאמץ 4 ב-Magento.
